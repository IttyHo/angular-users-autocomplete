# Angular Users Autocomplete

A focused Angular + TypeScript UI exercise implementing searchable user suggestions and autocomplete behavior. The project demonstrates reactive UI thinking, typed frontend code, API/data handling, and attention to responsive user interaction.

## What this project demonstrates

- Angular component design
- TypeScript
- Search/autocomplete interaction patterns
- Asynchronous data handling
- Clear separation of UI behavior and data access
- Frontend testing foundations

## Run locally

```bash
npm ci
npm start
```

Open `http://localhost:4200`.

## Build

```bash
npm run build
```
